# Fire Climb

A mobile-first React game: climb rising bars while the floor burns behind you.
Built with Vite + React + Tailwind CSS, packaged as an installable, offline-capable PWA.

## Develop

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

The production build is a static site (`dist/`) — deployable to any static host (Vercel, Netlify, etc).
